About motori.us

One record for every restomod build.

motori.us brings the same open documentation standard to every builder on it: a baseline, a public roadmap, and a dated log of the actual work.

How it works

One standard, applied to every build

Every build on motori.us gets documented the same way, so any two builds line up on equal footing.

Baseline

What the car actually is when work begins, backed by a real inspection.

Roadmap

What's planned and why, laid out in public before a part is ordered.

Updates

A working log as things actually happen, never rewritten after the fact.
